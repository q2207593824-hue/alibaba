# 店铺绑定公司名称显示问题 - 验收步骤

## 问题描述
会员账号绑定店铺后，自己的会员中心能看到公司名称，但管理员账号在会员列表中看不到该用户的公司名称。

## 修复内容
修改了 `backend/app/services/membership_service.py` 中的 `_merge_cloud_points_into_admin_users()` 函数，在从云端合并数据时，除了积分余额，还会同步合并 `company_name`、`main_category` 等 5 个资料字段。

2. **前端服务已启动**（默认端口 5173）

```json
{
```

- ✅ 如果 `ok: true, status: 200` → 云端写入成功
- ❌ 如果 `ok: false` → 查看 `detail` 字段的错误原因：
  - 可能是 `admin_api_key` 未配置
  - 可能是网络超时（timeout 只有 6 秒）

## 可能的失败原因和排查

### 原因 1：云端同步失败（`cloud_sync.ok = false`）
**症状**：
- 步骤 1.2 中 `cloud_sync.ok` 是 `false`
- `cloud_sync.detail` 里有错误信息

**排查**：
1. 检查配置文件 `backend/config.json` → `payment.admin_api_key` 是否配置
2. 检查网络连接（云端接口是否可达）
3. 查看后端日志（console 输出）

---

### 原因 2：本地 SQLite 的 `company_name` 字段为空
**症状**：
- 云端同步成功（`cloud_sync.ok = true`）
- 但管理员列表还是看不到公司名称

**排查**：
1. 检查是否启用了云端积分模式（`USE_CLOUD_POINTS=true` 或 `MEMBERSHIP_CLOUD_SYNC_ENABLED=true`）
   - 如果是纯本地模式，`_merge_cloud_points_into_admin_users` 不会被调用
2. 查看后端 SQLite 数据库（`backend/data/membership.db`）：
   ```sql
   SELECT id, username, company_name, main_category FROM users WHERE username='321654';
   ```
   - 如果 `company_name` 是空的，说明本地没写入

**解决**：
- 重新绑定店铺（会触发本地 SQLite 的 UPDATE）
- 或者用管理员账号手动更新该用户的资料

---

### 原因 3：前端缓存
**症状**：
- 后端数据已正确，但前端页面还是旧的

**解决**：
1. 硬刷新页面（Ctrl+Shift+R 或 Cmd+Shift+R）
2. 清除浏览器缓存
3. 打开无痕窗口（Ctrl+Shift+N）重新登录
