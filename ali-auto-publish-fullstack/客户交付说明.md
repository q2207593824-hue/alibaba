# Ali Auto Publish — 客户安装与使用说明

本文面向**最终客户**（非开发人员）。安装包由我方提供，客户无需安装 Python、Node.js 或配置数据库。

---

## 一、交付文件（任选其一发给客户）

打包产物目录：`frontend/release/`

| 文件 | 说明 | 推荐场景 |
|------|------|----------|
| `AliAutoPublish-1.0.0-win-x64.exe` | **安装版**（NSIS），可改安装路径、创建桌面快捷方式 | 正式交付、长期使用 |
| `免安装.exe` | **便携版**，解压到任意目录双击即用，不写注册表 | 试用、U 盘拷贝、无管理员权限 |
| `AliAutoPublish-1.0.0-win-x64.zip` | 绿色压缩包（含完整 `win-unpacked` 目录） | 内网分发、杀毒软件拦截 exe 时备用 |

> 安装包体积约 380MB，内含 Electron 壳、本地后端与浏览器自动化依赖，属正常现象。

---

## 二、客户环境要求

- **操作系统**：Windows 10 / 11，64 位
- **网络**：能访问互联网（会员登录、积分、充值走云端 `https://echo-yiwu.cloud`）
- **浏览器**：首次使用发品/自动化功能时，程序会引导安装 **Google Chrome**（或按界面提示完成 Playwright 浏览器组件）
- **绑定店铺**：必须已安装 **Google Chrome**；安装包已内置 ChromeDriver，首次绑定若 Chrome 版本较新可能需要联网自动更新驱动
- **磁盘**：建议预留 **2GB** 以上可用空间（程序数据与日志在 `%AppData%\AliAutoPublish\`）
- **权限**：安装版建议以管理员运行安装程序；日常使用普通用户即可

**不需要**：Python、Node、SQLite 手工配置、本地搭建会员服务器。

## 三、安装与启动

### 方式 A：安装版（推荐）

1. 双击 `AliAutoPublish-1.0.0-win-x64.exe`
2. 按向导选择安装目录（默认即可）
3. 安装完成后从桌面或开始菜单打开 **Ali Auto Publish**
4. 首次启动会稍等数秒（本地服务 `127.0.0.1:8000` 自动拉起）

### 方式 B：免安装版

1. 将 `免安装.exe` 复制到客户电脑任意文件夹（路径尽量**不要含特殊字符**）
2. 双击运行；数据仍保存在 `%AppData%\AliAutoPublish\data`

## 四、登录与进入系统

1. 打开软件后进入 **会员中心**
2. 使用我方提供的 **会员账号 / 密码** 登录（账号在云端统一管理）
3. 登录成功后点击 **进入系统**，即可使用发品、数据分析等功能
4. 发品、配置、任务等业务在**本机**执行；**会员、积分、充值**在**云端**校验

若提示「云端会员服务不可用」：

- 检查本机是否能打开 https://echo-yiwu.cloud
- 关闭或调整「全局代理 / 安全软件 HTTPS 扫描」后重试
- 部分网络需将 `echo-yiwu.cloud` 解析到正确 IP（我方技术支持可提供 hosts 条目）

### 客户只有 CMD 时，如何自测云端登录？

将安装包附带的 `scripts\customer-test-cloud-login.cmd` 发给客户，**右键 → 以管理员身份运行**（普通运行也可）。  
或在 **cmd** 里执行（把账号密码改成客户自己的）：

```cmd
powershell -NoProfile -Command "$b=@{username='321654';password='Aa23456'}|ConvertTo-Json -Compress; Invoke-RestMethod -Method POST -Uri https://echo-yiwu.cloud/api/membership/auth/login -ContentType application/json -Body $b"
```

- 若显示 `success : True` → 本机网络与账号正常，软件仍报错则多为**旧安装包**，需重装最新版。
- 若失败 → 先解决网络/代理，再登录软件。

> 不要用 `curl -d '{"..."}'` 测（在 Windows 下 JSON 容易被弄坏）。

## 六、常见问题

**Q：双击后白屏或很久没反应？**  
等待 30～60 秒；查看 `runtime.log` 是否出现后端启动失败。关闭占用 **8000** 端口的其他程序后重启软件。

**Q：会员能登录但「进入系统」失败？**  
多为本地会话同步失败，请更新到最新安装包；仍失败时将 `runtime.log` 发给技术支持。

**Q：发品时浏览器打不开？**  
请先安装 [Google Chrome](https://www.google.com/chrome/)。绑定店铺依赖 Chrome + ChromeDriver；若提示 `Unable to obtain driver for chrome`，多为未装 Chrome 或网络无法下载驱动，请更新到最新安装包后重试。

**Q：绑定店铺提示 ChromeDriver 失败？**  
1. 确认本机已安装 Chrome 并能手动打开  
2. 关闭拦截 HTTPS 的安全软件后重试  
3. 仍失败时将 `%AppData%\\AliAutoPublish\\logs\\runtime.log` 发给技术支持

**Q：积分扣减异常？**  
确认云端服务正常；本地仅执行扣减请求，余额以云端为准。

## 七、我方（开发商）打包前检查清单

交付客户前请确认：

- [ ] 云端 `echo-yiwu.cloud` 已配置 `MEMBERSHIP_IS_CLOUD_HOST=1`、`MEMBERSHIP_POINTS_SOURCE=local`，启动文件为 `run_cloud.py`（见 `docs/宝塔云端-Python项目管理.md`）
- [ ] 腾讯云安全组已放行 **80、443**；客户机 Clash 需将 `echo-yiwu.cloud` 设为 **DIRECT**（或 hosts：`43.164.196.172 echo-yiwu.cloud`）
- [ ] 已用 **最新** `scripts/build-desktop.ps1` 打包，并安装 `frontend/release/` 内新 exe（勿用旧包）
- [ ] 本机自检：`curl http://127.0.0.1:8000/api/health` 含 `ali-auto-publish-backend`；`curl https://echo-yiwu.cloud/api/health` 含 `ali-membership-cloud`
- [ ] 安装后任务管理器仅 **1 个** `ali-backend.exe`；勿与 `python run.py` 同时占用 8000
- [ ] 管理员在「流量分析 / 产品优化 / AI 生图」保存 API Key 后，其他客户端 3 秒内自动同步（需已登录会员）
- [ ] 已向客户提供测试账号；已说明 Chrome 与网络要求

## 八、开发商重新打包命令（Windows）

在项目 `frontend` 目录执行：

```powershell
# 可选：结束占用进程
taskkill /F /IM "Ali Auto Publish.exe" 2>$null
taskkill /F /IM ali-backend.exe 2>$null

cd frontend
pnpm install
pnpm run desktop:build
```

或运行根目录脚本：`powershell -ExecutionPolicy Bypass -File scripts\build-desktop.ps1`

成功后产物在 `frontend\release\`。
